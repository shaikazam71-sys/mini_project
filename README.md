#  Personal Expenses Analytics & Data Pipeline

A mini project for processing and analyzing expense transaction data using Python, Pandas, and MySQL.

## 📌 Features
- **ETL Pipeline:** Extracted expense data from CSV files and transformed it using Pandas (`pandas_etl.py`).
- **Database Integration:** Established a direct connection to MySQL using Python (`mysql_connection.py`) to store and query processed expense data.
- **Data Analytics:** Structured transaction metrics for analysis and reporting.

## 🛠️ Tech Stack
- **Language:** Python
- **Libraries:** Pandas, SQLAlchemy / MySQL Connector
- **Database:** MySQL
- **Data Format:** CSV
